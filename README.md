# Kabuki Joki
Website statis HTML, CSS, dan JavaScript.

## File utama
- `index.html`: konten, layanan, harga, dan formulir order.
- `style.css`: tampilan responsif biru-hitam.
- `script.js`: formulir order WhatsApp.

## WhatsApp admin
Nomor yang dipasang: 08984814123, ditulis dalam format internasional sebagai `628984814123`.

## Harga
Harga semua layanan ditampilkan sebagai "Hubungi Admin" karena harga ditentukan secara custom. Paket 10 bintang mendapatkan bonus 2 bintang (total 12 bintang).

## Upload dan deploy
Upload ketiga file utama ke root repository GitHub. Di Vercel pilih Framework Preset `Other`, kosongkan Build Command dan Output Directory, lalu Deploy.
